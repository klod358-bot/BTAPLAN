# BTAPLAN

План перехода на 1С:Бухгалтерию и 1С:ЗУП с 01.01.2027 — диаграмма Ганта.

Страница `index.html` открывается через GitHub Pages. Содержимое плана зашифровано (AES-256-GCM, ключ из логина и пароля через PBKDF2, 600 000 итераций) и расшифровывается в браузере только после ввода логина и пароля. Логин и пароль в репозитории не хранятся.

Обновление: план собирается из `План_перехода_БК_ЗУП_2027.xlsx` и шифруется заново — файл `index.html` просто заменяется.
